# Qorgan: умный подбор подрядчиков

Рабочий P0 для HackAlem AI 2026, case #79-lite: заказчик задаёт параметры мероприятия и получает до трёх доступных подрядчиков из официального каталога.

## Задача и пользователь

Заказчику event-площадки нужно выбрать подрядчика из уже существующего каталога своего города. Длинный список не отвечает на вопросы о занятости, бюджете и пригодности для конкретного события. Сервис проверяет эти условия, показывает причины отсева и объясняет каждую рекомендацию фактами из профиля.

## Что реализовано

- Форма → `POST /api/recommend` → CSV → фильтрация → сортировка → карточки.
- Статусы `matched`, `no_category`, `no_eligible`; при неполной выдаче есть `shortfall`.
- `rejected[]` сохраняет **все** причины отсева: `busy`, `over_budget`, `format`, `language`, `duration`.
- Pipeline показывает, сколько профилей осталось после каждого последовательного этапа.
- Карточки показывают происхождение синтетических профилей и восстановленных города/цены.

## Архитектура

`lib/catalog.ts` читает `data/contractors.csv` через PapaParse (`header: true`) и нормализует типы. `lib/search.ts` проверяет вход через Zod. `lib/match.ts` содержит чистый детерминированный matcher: точный каталог по городу и категории, все причины отсева, последовательный pipeline, сортировку и объяснения. `app/api/recommend/route.ts` обрабатывает запросы и ошибки. Форма находится в `components/SearchForm.tsx`.

Выбрал детерминированную фильтрацию, потому что календарь, бюджет и другие жёсткие ограничения должны проверяться гарантированно. AI-слой анализа свободного описания запланирован отдельным этапом и **в этом P0 не реализован**. Сейчас объяснение состоит из проверенных структурированных фактов и короткой цитаты из исходного `description`; LLM не вызывается и не влияет на порядок.

## Данные и схема

В `data/contractors.csv` находятся 66 анонимизированных профилей официального датасета. Списки `categories`, `event_formats`, `languages`, `busy_dates` разделены `|`; `True`/`False` превращаются в boolean, пустой `max_hours` в `null`. CSV разбирается с учётом запятых, кавычек и переносов строк в описании. `max_hours: null` означает, что ограничение длительности присутствия не применяется.

Обязательный вход: `city`, `date`, `eventType`, `category`, `budgetKzt`. Необязательный: `durationHours`, `language`. Дата должна существовать в календаре и находиться в диапазоне `2026-09-23` — `2026-12-31`. Город, формат и язык проверяются по допустимым значениям; бюджет должен быть положительным целым числом. Длительность, если задана, должна быть целым числом от 1 до 24 часов. Категория проверяется Zod-схемой по Set категорий из реально загруженного CSV: неизвестная категория возвращает HTTP 400, а `no_category` означает отсутствие известной категории в выбранном городе.

## Фильтры и ранжирование

Каталог формируется по точному совпадению города и категории. Затем каждый профиль независимо проверяется на занятость, бюджет, формат, язык и длительность. В выдачу попадают только профили без причин отсева. Pipeline применяет эти проверки последовательно, поэтому кандидат учитывается на каждом этапе только один раз; в `rejected[]` у него может быть несколько причин.

Подходящие профили сортируются по возрастанию цены, затем при указанной длительности по убыванию запаса часов (`null` означает отсутствие лимита), затем по стабильному `id`. Возвращаются первые три. Рейтинги качества и вероятность выбора не вычисляются: таких данных нет.

## Технологии и системные требования

Next.js App Router, React, TypeScript strict, Tailwind CSS, Zod, PapaParse. Для локального запуска нужны Node.js 24 и npm 11; проверено в этом окружении с Node.js 24.11.1 и npm 11.6.2.

## Установка и запуск

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

Открыть `http://localhost:3000`. Для production-сборки:

```powershell
npm run build
npm run start
```

`.env.example` содержит пустые `OPENAI_API_KEY` и `OPENAI_MODEL` для будущего AI-этапа. P0 не читает и не требует эти значения; оставьте их пустыми. `.env.local` и остальные реальные env-файлы исключены из Git.

## Проверки

```powershell
npm run typecheck
npm run lint
npm test
npm run build
```

Тесты работают с реальным CSV и проверяют 66 уникальных профилей, детерминизм ordered result IDs, календарь, `max_hours: null`, статусы, максимум три результата, все причины отсева и последовательный pipeline. Валидация проверяется на несуществующих и выходящих за диапазон датах, границах диапазона, неположительном бюджете, дробной и выходящей за 1–24 длительности, неизвестной категории. Все четыре команды были выполнены успешно.

## Как проверить основной сценарий

Отправить параметры через форму или `POST /api/recommend` с JSON. Реальные результаты локального API:

| Демо | Вход | Ожидаемый и полученный результат |
| --- | --- | --- |
| A | Астана, `2026-09-23`, свадьба, Ведущий, 1 000 000 ₸, 8 ч, казахский | `matched`: 4 из 5 подходят, показаны Идзуку Мидория (600 000 ₸), Нами и Санджи Виндсмок (по 800 000 ₸); Крилин отсеян по формату, языку и длительности. |
| A2 | То же, дата `2026-09-24` | `matched`: остаётся Санджи Виндсмок; shortfall называет занятых Нами, Идзуку Мидорию и Тэнъю Ииду. |
| B | Астана, `2026-09-23`, корпоратив, Флорист, 500 000 ₸, русский | `matched`: Хаку (300 000 ₸), один профиль в каталоге; синтетический badge. |
| C | Астана, `2026-09-23`, свадьба, Ведущий, 500 000 ₸ | `no_eligible`: 5 профилей, ни один не проходит; минимальная цена 600 000 ₸. |
| Нет категории | Астана, `2026-09-23`, свадьба, Декоратор, 1 000 000 ₸ | `no_category`; подсказка: Алматы — 3 профиля. |

Пустой или неверный ввод возвращает HTTP 400 с понятной ошибкой; например, нулевой бюджет и дата вне диапазона. Ошибка чтения каталога возвращает HTTP 500 без стектрейса и секретов. В UI есть состояния загрузки, результата, некорректного ввода и ошибки сервера.

## Известные ограничения и деплой

В P0 нет AI-анализа описания, бронирования, базы данных и авторизации. Детерминированная цитата из описания может быть менее выразительной, чем проверяемое AI-объяснение будущего этапа. Визуальная проверка в браузере в текущем окружении не выполнена: браузерная поверхность недоступна. Деплой и URL ещё отсутствуют.
